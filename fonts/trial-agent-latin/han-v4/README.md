# Han v4 trial: calligraphic skeletons simplified into one UI brush

- `han24-v4.pips`: the 24 characters after the normalisation rules in
  [../source/hanv4.py](../source/hanv4.py), in the same compact format as v3.
- `v4.woff2`: drawn from the decoded file by the near-monoline UI brush.
- `round1.png`, `round2.png`: the first two polish rounds; the third is
  [../specimens/08-han-v4.png](../specimens/08-han-v4.png).
- `report.json`: sizes and timings from [../source/run_v4.py](../source/run_v4.py).

The stroke data comes from Make Me a Hanzi, so this directory is under the
Arphic Public License, like [../han-v3/](../han-v3/) ([licence text](../han-v3/LICENSE-APL.txt)).
