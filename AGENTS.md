# SylphxAI/brand — agent notes

The one home of the Sylphx identity (owner standard `standards/experience.md`,
"Brand home"). Start at [README.md](README.md).

- Never edit a generated file (`logo/svg`, `logo/png`, `logo/favicon`,
  `logo/app-icon`, `logo/sheet`, `tokens/brand.css`, `logo/MANIFEST.sha256`):
  change `logo/construction/mark.spec.json` or `tokens/brand.tokens.json`,
  run the three commands in the README, and commit the outputs with the
  source, because surfaces pin these files by hash.
- A new mark or direction lands here first, with a similarity check recorded
  in `directions/`, and then the surfaces follow.
- Product brands, “by Sylphx” endorsement, publisher-only exceptions and
  sign-in naming follow [docs/name.md](docs/name.md).
