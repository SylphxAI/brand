# The name

| Form | Use |
| --- | --- |
| **Sylphx** | The company and the platform, in running text, titles and the logo. One word, capital S, the rest lower case. |
| **Sylphx Limited** | Legal documents, contracts, invoices and copyright lines only. |
| **Sylphx ⟨Service⟩** | A platform service, always in this form: Sylphx Hosting, Sylphx Data, Sylphx Auth, Sylphx AI. Never a service name alone as a brand, and never a second word order. |
| **`sylphx`** | Code, the CLI, package names (`@sylphx/sdk`), hosts (`sylphx.com`, `api.sylphx.com`). Lower case. |
| **SylphxAI** | The GitHub organization identifier only. Never a product or company name in customer copy. |

- Never *SylphX*, *Sylph X*, *SYLPHX* in running text, or *Sylphx's* for a
  service ("Sylphx Data", not "Sylphx's database product").
- Capitals appear only in the logo image, which is drawn, never typed.
- Pronounced *silfs* (like *sylph*, the air spirit, with an x).
- **Chinese and Japanese:** the name stays in Latin letters in every locale,
  with no transliteration, and service names stay in English (Sylphx Data in
  a Traditional Chinese page, not a translated service word).
- **Apps are not Sylphx.** Products we build on the platform carry their own brands and never the Sylphx name or
  mark, on any surface. The platform never presents an app as a service.

Naming law, the lifecycle register and retired names live in the owner
repository: [portfolio.md](https://github.com/SylphxAI/owner/blob/main/company/portfolio.md)
and [names.md](https://github.com/SylphxAI/owner/blob/main/company/names.md).
