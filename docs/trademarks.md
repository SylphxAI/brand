# Trademark status

**Sylphx Limited holds no registered trademark and has no application
pending, on any register searched**, for the name Sylphx or the mark. We use ™ on the
name where a symbol is wanted; never ®.

A row is added here, with office, number, class, owner entity, status,
renewal date and the date it was read on the register, the day anything is
filed.

This is deliberate. The company is small and self-funded, and the owner's
standing decision (2026-09-27, owner#781) is to file nothing and pay for no
clearance before a product earns money or a real problem appears.

What we did instead, sized to that:

- **The mark** was chosen 2026-09-28 after a visual comparison with the marks
  of 25 developer platforms and our own brands
  ([directions/README.md](../directions/README.md#similarity-check),
  [directions/out/similarity-competitors.png](../directions/out/similarity-competitors.png)).
  No resemblance was found. This is a sanity check, not a legal search.
- **The name** has been in public use since 2025 on sylphx.com, the SylphxAI
  GitHub organization and the `@sylphx` npm scope.

Revisit when revenue justifies it, or when someone challenges the name or
mark.
